# Atribuição do SRD 5.1

Este diretório (`packages/shared/src/srd/`) contém dados mecânicos mínimos (classes com dado de vida,
salvaguardas, tipo de conjurador e habilidade de conjuração; perícias com o atributo; tabelas de espaços
de magia) tirados do **System Reference Document 5.1 ("SRD 5.1")**, de Wizards of the Coast LLC, publicado
em <https://dnd.wizards.com/resources/systems-reference-document>.

O SRD 5.1 é licenciado sob a **Creative Commons Attribution 4.0 International License (CC-BY-4.0)**,
disponível em <https://creativecommons.org/licenses/by/4.0/legalcode>.

Mudanças feitas: os nomes das perícias e das classes foram traduzidos para o português do Brasil e os
dados foram reescritos como código TypeScript. Nenhum texto de magia, de característica ou de item está
neste diretório: isso fica para o compêndio (Lote 14) e para o que cada mesa digitar.

As tabelas de multiclasse (conjurador de nível N para espaços por nível) e do Bruxo (espaços de pacto)
vêm do Livro do Jogador de 2014, que repete as tabelas do SRD; aqui só entram os números.
