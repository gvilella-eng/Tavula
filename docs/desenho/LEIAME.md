# Protótipos da ficha (aprovados em 2026-11-11)

São HTML de um canvas de protótipos (com o runtime dele). Leia como texto: o CSS do `<helmet>` dá medidas, fontes e cores; o `<script type="text/x-dc">` dá o comportamento. Não é código para colar.

- `FichaFinal.dc.html`: a ficha larga do personagem. É a fonte da verdade.
- `FichaFinalEstreita.dc.html`: a mesma ficha numa janela estreita (~460 px): cabeçalho grudado e acordeão.
- `FichaA.dc.html`: a pele "Clássica" (direção A).
- `NpcN.dc.html`: o NPC. Não foi implementado no V4a; é o V4b.

Dois ajustes do Vilella valem por cima: a janela abre com ~880 px (a coluna da direita ganha o espaço) e os títulos de Salvaguardas e Perícias ficam em cima, no estilo ornamentado.
